# MineScale-Java

[English README →](README-EN.md)

**マイクラ（Java版）のワールドを、友達と一緒に遊ぶ。それだけ。**

URL をひとつ送るだけ。友達のマイクラに、あなたのワールドが出てきます。

---

## こんなこと、必要ありません

❌ ルーターの設定（ポート開放）
❌ アカウント登録
❌ サーバー契約
❌ 月額料金
❌ VPN ソフトのインストール
❌ ネットワークの知識
❌ サーバー（realms など）の購入

✅ アプリを開く
✅ ボタンを押す
✅ 出てきた URL を友達に送る

これだけです。

ふつうは、ルーターのポート開放、グローバル IP の固定、realms の月額契約、VPN ソフトの導入と
アカウント登録、サーバーの建立と運用……と、めちゃくちゃ面倒です。
MineScale-Java は、これら全部を **裏側で自動的に** やります。

---

## 使い方（GUI 版・おすすめ）

### ホスト（ワールドを公開する人）

1. マイクラでワールドを開いて、ESC →「LAN に公開」
2. `mc-share-gui` をダブルクリックで起動
3. 「Host」を押す
4. 出てきた URL をコピーして、友達に LINE / Discord など好きな方法で送る

### ジョイン（参加する人）

1. `mc-share-gui` を起動
2. 「Join」タブを開いて、もらった URL を貼り付ける
3. 「Connect」を押す
4. マイクラを開く → マルチプレイ → 友達のワールドが勝手に出てくる
5. クリックして入る。以上。

> うまく出てこないときは、[トラブルシューティング](docs/TROUBLESHOOTING.md)の
> 「直接アドレスを入力する」方法で確実に入れます。

### Windows は winget でも入れられます

PowerShell を開いて、次を実行します。

```powershell
winget install minescale
```

これだけで、`mc-share-gui` が使えるようになります。

> Windows で「一般的にダウンロードされていません」などの警告が出たら、
> [トラブルシューティング](docs/TROUBLESHOOTING.md)を見てください（winget なら出ません）。

## よくある質問

**Q. 危なくないの？ 知らないサーバーを経由するんでしょ？**
A. 通信は 2 通りの経路のどちらかを通ります。アプリの画面に **今どちらか** が表示されます。

- **Direct (P2P)**: あなたと友達の間で直接つながり、MineScale が暗号化します。
  間のサーバーは「お互いのアドレスを伝えるだけ」で、ゲームの通信には関わりません。
- **Relay (via server)**: 直接つながらない回線（会社のネットワークなど）では、サーバーを**経由**します。
  この経路では MineScale による暗号化は**ありません**（サーバーは通信を保存・解析しない作りですが、
  通過はします）。サーバーの運営者を信頼できる前提の経路です。

**Q. ワールドを乗っ取られたりしない？**
A. **URL が入室の唯一の鍵**です。URL を知っている人は、発行から約 15 分間なら誰でも入れます
（参加の承認・人数制限・URL の無効化はありません）。SNS など公開の場に貼らないでください。
参加する側のパソコンの**中だけ**にワールドが見える設計で、同じネットワークの他の端末には
表示されず、接続も拒否されます。

**Q. 友達が途中から入れなくなった**
A. 新しく入れるのは、URL の作成から約 15 分間です。過ぎたら、もう一度「Share World」で
新しい URL を発行してください（すでに入っている人は、そのまま遊べます）。

**Q. ラグくない？**
A. Direct (P2P) のときは追加の遅延はほぼありません。Relay のときは、サーバーを 1 回経由する分だけ
遅延が増えます。

**Q. お金かかる？ アカウント登録は？**
A. かかりません。メールアドレスも電話番号も不要です。

**Q. ホストの人がマイクラを閉じたらどうなる？**
A. ふつうの LAN マルチと同じで、みんな抜けます。

**Q. 何人まで遊べる？**
A. マイクラの「LAN に公開」と同じ上限です（ホストの PC と回線次第）。

## 接続調査への協力について（任意・デフォルトオフ）

> このセクションは **アプリ内には一切表示しません**。
> UI から協力を求めることはしません。

MineScale-Java は「どの NAT 構成・OS で接続が成功／失敗するか」を改善するため、
**任意の opt-in 方式で** 接続診断データを収集できる仕組みを持っています。
**デフォルトでオフ**。アプリ内のボタンや通知から有効化することはできません。

協力していただける方は、起動時に次の方法でオンにできます:

```bash
# CLI
mc-share host --telemetry
mc-share join <URL> --telemetry

# GUI（フラグでも環境変数でも OK）
./mc-share-gui --telemetry
MC_SHARE_TELEMETRY=1 ./mc-share-gui      # Windows 以外
```

> Windows のエクスプローラからダブルクリック起動する場合は、
> 起動用ショートカットを作って「リンク先」に `--telemetry` を追加する形が一番楽です。

### 送信される情報（これだけです）

| 項目 | 例 | 用途 |
|------|---|------|
| `session_id` | ランダム 16 文字 | 同一セッション内の start/result を紐付け（永続化なし） |
| `room_id` | 共有 URL の末尾 | host と join のペアリング（部屋自体は 15 分で消えます） |
| `role` | `host` / `join` | どちら側か |
| `phase` | `start` / `registered` / `connected` / `result` | 進捗マイルストーン（各イベント直後に送信） |
| `outcome` | `success` / `cancelled` / `stun_failed` / `punch_failed` / `tls_failed` / ... | 成否カテゴリ（`result` のみ） |
| `transport` | `quic` / `relay` | 実際に使われた経路（接続成立時のみ） |
| `duration_ms` | `3421` | 開始から結果までの所要時間 |
| `nat_type` | `Cone NAT (P2P ready)` 等 | NAT 種別（診断パネルと同じ判定） |
| `ipv6_available` | `true` / `false` | IPv6 経路の有無 |
| `os` / `os_detail` | `macos` / `macOS 14` | OS の系統とメジャーバージョン |
| `arch` | `aarch64` / `x86_64` | CPU アーキテクチャ |
| `app_version` | `1.1.0` | アプリのバージョン |
| `app_kind` | `cli` / `gui` | フロントエンドの種類 |

### 送信されない情報（明示的に除外しています）

- ❌ ユーザー名、ホスト名、MAC アドレス、メールアドレス
- ❌ あなたのグローバル IP / ローカル IP / 外部アドレス（STUN 結果含む）
- ❌ Minecraft のインストール済みバージョン一覧
- ❌ OS のマイナー／ビルド番号（例：「14.5.1 (23F79)」→「14」までに丸めます）
- ❌ ゲームデータの中身
- ❌ 永続的な端末識別子

### サーバー側の取り扱い

- 受信時の **送信元 IP アドレスは記録しません**
- HTTP リクエストヘッダも記録しません
- 上記の JSON 本文に、サーバー側で受信時刻のみを付けて JSONL に追記します
- 部屋 ID 自体は 15 分で消えるため、長期的にあなたを再識別する手段はありません

### 目的

- 「どの NAT タイプ × どの OS の組み合わせなら成功するか」の統計を取る
- 失敗パターンの再現条件を絞り込む
- 将来の安定性向上（hole punch ロジックや fallback の調整）に役立てる

### 利益相反なし

- 広告 / マーケティング目的では使いません
- 第三者には共有しません
- 取得データは集計後に削除します

### やめ方

- CLI: フラグや環境変数を外すだけ
- GUI: `MC_SHARE_TELEMETRY` 環境変数をセットしないで起動するだけ
- 一度送ったデータの削除を希望する場合は `session_id` を添えて GitHub の Issue でご連絡ください
  （`session_id` はアプリのログ ── `RUST_LOG=debug` 等 ── に出ます）
